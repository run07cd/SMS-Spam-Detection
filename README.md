# SMS Spam Detection

A basic model that classifies text messages as spam or not spam.

## Run

```bash
pip install -r requirements.txt
python main.py
```

The script downloads the SMS Spam Collection dataset from the [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/228/sms%2Bspam%2Bcollection) the first time it runs. An internet connection is needed for the initial download.
